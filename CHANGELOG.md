# Changelog

Versions follow `MAJOR.MINOR.PATCH`. See "Versions and changes" in the README.

## 0.1.0

First release.

- **Foundations:** theme (colours, typeface, type scale, spacing, radii, sizes,
  elevation, per-component text styles), icons (SF Symbols and brand icon
  sets), haptics, materials, motion.
- **Components:** buttons, icon buttons, tappable cards, text and password
  fields (with a public field layout), rows, section headers, banners, tags and
  count badges, chips, segmented control, step indicator, state views (empty,
  error, offline), loading placeholders, toast (with an action), avatars,
  remote images, sheet toolbar, bottom action bar.
- **Open variants:** button kinds, banner kinds, tag tones, toast kinds.
- **Guides:** README (adopting and extending), PATTERNS.md (navigation, forms,
  destructive actions, states, feedback, permissions, keyboard, writing).
- **Catalog app** with a page per component and reference screens for three
  patterns.
